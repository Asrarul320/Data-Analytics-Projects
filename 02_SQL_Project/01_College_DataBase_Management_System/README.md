# 🎓 College Management System SQL Project

## 📌 Project Overview

The College Management System is a SQL-based database project developed using MySQL. The project is designed to manage student records, courses, departments, semesters, marks, and fee details. It demonstrates fundamental and intermediate SQL concepts commonly used in Data Analytics.

---

## 🎯 Objectives

* Design a relational database for a college.
* Store and manage student information.
* Perform academic and fee analysis.
* Practice SQL queries from basic to intermediate level.
* Solve business-oriented SQL problems.

---

## 🛠 Tools Used

* MySQL
* MySQL Workbench

---

4. Semesters
